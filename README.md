# Invisible Movement — сборка

Здесь лежит готовая сборка мода Invisible Movement. Она обновляется автоматически: и у игроков, и на сервере
новая версия подтягивается сама при запуске. Исходный код проекта хранится отдельно.

## Игроку: установка один раз

Нужен купленный Minecraft Java Edition.

1. Скачай и установи [Prism Launcher](https://prismlauncher.org/download/).
2. Войди в свой аккаунт Microsoft: значок аккаунта справа вверху → «Управление аккаунтами» → «Добавить Microsoft».
3. «Добавить сборку» → «Импорт» → вставь ссылку:
   `https://github.com/matthewbkrr/invisiblemovement-pack/raw/main/InvisibleMovement.zip`
4. Нажми «Играть». Перед стартом появится окошко обновления модов — это нормально, так приходят обновления.
5. «Сетевая игра» → «Добавить сервер» → адрес, который даст хозяин сервера.

Дальше ничего делать не нужно: каждое обновление скачивается само, когда жмёшь «Играть».

## Хозяину сервера: установка один раз

1. Установи Java 25: [adoptium.net](https://adoptium.net/temurin/releases/?version=25) (Windows, x64, JDK, `.msi`).
2. Скачай и распакуй в отдельную папку:
   `https://github.com/matthewbkrr/invisiblemovement-pack/raw/main/InvisibleMovement-server.zip`
3. Запусти `start.bat`. В первый раз он попросит принять [EULA Minecraft](https://www.minecraft.net/eula):
   открой `eula.txt` и впиши `eula=true`, затем снова запусти `start.bat`.
4. Когда в окне появится `Done`, впиши в это окно команды:
   - `op ТвойНик` — сделать себя оператором;
   - `whitelist add НикДруга` — пустить друга. Чужих сервер не пустит.
5. На роутере пробрось порт `25565` (TCP) на этот компьютер и разреши его в брандмауэре Windows.
   Друзья подключаются по адресу `твой-внешний-IP:25565`, ты сам — по адресу `localhost`.

Перед каждым запуском `start.bat` сам скачивает свежую сборку (и новую версию своего скрипта) и делает резервную копию мира в папку `backups`
(хранятся 10 последних). Чтобы обновить сервер, останови его командой `stop`: через 10 секунд он перезапустится
уже с новой версией. Чтобы выключить совсем, закрой окно во время этой паузы.

## Если вышла новая версия Minecraft

Моды обновляются сами, а версию Minecraft в Prism нужно поменять один раз вручную: правой кнопкой по сборке →
«Изменить» → «Версия» → выбрать Minecraft и Fabric из `pack.toml` (строки `minecraft` и `fabric`).
Сервер подхватит новую версию Minecraft сам.
